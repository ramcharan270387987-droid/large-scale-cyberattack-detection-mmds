# Phase 9 C hierarchy methodological amendment

The archived C binary gates keep the original capture split, checksum-pinned
pipelines and frozen decision thresholds. The test days are 22 and 23 February
2018. Some dates in the original binary training and validation roles come
after this window. The C hierarchy is a retrospective comparison.

For the new family classifier, the eligible training and calibration traffic
consists of retained C training-role attacks dated before 22 February. All Web
attack observations remain excluded from both roles. C's original validation
day follows the test window and supplies no earlier calibration observations.
A deterministic predictor-group hash, seeded with 23013 and salted for C
calibration, assigns 85% of eligible groups to family fitting and 15% to
family validation. The split is defined here before C family fitting.

The 6.25% grouped fitting sample, candidate grid, feature preprocessing,
selection order, supported-class mapping and rejection methods use phase9-v1.
The hierarchy uses the existing maximum-score rejection rule at the 5%
calibration budget, matching B. The complete retained C test population
remains fixed, including benign traffic and missed attacks. The family
classifier and training-reference K-Means will be saved in the private C
notebook output with model hashes and synthetic reload probes.
