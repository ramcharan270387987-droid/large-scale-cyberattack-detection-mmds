# Phase 11 methodology

River 0.22.0 supplies ADWIN, Page-Hinkley, KSWIN and binary DDM. The committed compatibility receipt records actual constructor signatures. Updates preserve library reset semantics. No external reset is imposed after an alert. Snapshot parity and duplicate-batch suppression were independently checked for all four adapters using trusted local state files.

Calibration uses independent stationary seeds and reports every configuration's realized alert rate. The implemented primary selector first prefers candidates satisfying the stationary budget, then lower stationary false alarms and lower measured CPU cost. Stationary calibration cannot evaluate missed changes. Thus no evaluation episode recall enters selection. This resolves the protocol's reference to minimizing misses when only stationary calibration is available. JS and PSI use frozen calibration quantile thresholds and 1e-6 count smoothing. Fixed JS uses .1. JS is measured in bits. PSI uses natural logarithms.

Synthetic distribution episodes and error episodes are distinct targets. Binary DDM has true episodes only for error and concept scenarios. Label-free signal detectors have no true feature episodes in the error and concept scenarios. Synthetic prior observations use immediate released simulated labels. The explicit concept scenario reverses the controlled sign-to-label relationship while holding the feature generator fixed. Missingness is monitored as an indicator. Gradual shift mixes old and shifted concepts probabilistically, while incremental shift continuously changes the mean.

The primary synthetic streams contain 4096 observations and 256 warm-up observations, three evaluation seeds and disjoint calibration seeds. The 512-observation event-matching horizon allows one matched alert per event. Additional in-horizon alerts are separately counted as repeats. Outside-horizon alerts are excess alerts. Delay is undefined for undetected events. Label delays are zero, one or three 64-observation windows. End-of-stream unreleased labels remain pending. No later labels are flushed into earlier predictions.

Historical analysis reuses the saved Phase 6 Spark aggregates, including 47 intraday windows and two capture-only anomaly batches. Their sum is 15,322,987 retained flows. The first three batches define the RF histogram reference. Batches three through nine calibrate JS and PSI using their maximum observed divergence. Remaining batches are retrospective evaluation. The two low-support anomaly batches remain in the population reconciliation but are ineligible for detector updates under a minimum support of 100. Feature timing remains tied to the original replay batch and capture-day provenance.

Historical observation-level algorithms receive one aggregate RF score-mean per supported replay window. Error-rate updates use released aggregate errors and are explicitly measured in windows. The historical aggregates omit the original binary-error sequence, so historical binary DDM is unsupported. KSWIN's 100-observation warm-up exceeds the 49-window history. Its historical lack of alerts provides no efficacy evidence. Neither saved aggregate stream is described as raw-flow drift detection. No authoritative historical drift-event labels exist.

Sensitivity compares JS and PSI windows of 32, 64 and 128 observations, mean-shift magnitudes .5 and 1, and three seeds. The label-free ensemble requires two distinct detector families within 64 observations and applies a 64-observation cooldown. No-detector and fixed-JS controls remain visible. Serialized state size measures checkpoint bytes, and update rates measure the stated bounded experiment. They do not establish multi-node scaling.
