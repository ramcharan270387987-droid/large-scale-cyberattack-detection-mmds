# Phase 13 research contribution

This phase ties each explanation to a reproducible archived model, preprocessing order, source version and component hash. Exact logistic logit reconstruction, centroid distance decomposition and hybrid fusion reconstruction make the explanation auditable against the issued scoring implementation. The centered linear interventional SHAP game has an independent coalition-enumeration check, and optional library explanations have separate compatibility and additivity gates.

The study combines matched permutation experiments, chronological reference-bin distributions, outcome/family/capture-conditioned contributions and prespecified adaptive model comparisons. Repeated sample/background seeds, sample sizes, capture composition and duplicate weighting expose sensitivity rather than selecting one favorable ranking. The duplicate-group metadata amendment separates numerical explanation correctness from conditional-label validity.

Its contribution is a traceable retrospective account of which model inputs accompany weak chronological detection, novelty/rejection behavior and mixed adaptive refresh outcomes. It supplies model-dependence evidence and explicit negative findings. It does not establish causal attack mechanisms, prospective operational effectiveness or an optimal mitigation policy.
