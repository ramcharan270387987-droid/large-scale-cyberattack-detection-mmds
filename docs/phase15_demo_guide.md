# Phase 15 academic demonstration

Start the isolated advanced entry point with the deployment-guide command. No public deployment is claimed.

1. Executive overview:show source/external populations and explain chronological/generalization limitations.
2. Browse the nine research areas. Select an evidence table,filter a protocol/model/capture where supported,and download its content-bound CSV. Explain grouped-random versus chronological evaluation,conditional/oracle family gates,synthetic versus historical drift,simulated delayed labels and single-machine scalability.
3. Interactive inference:select LR,RF or K-Means. Choose a clearly labeled synthetic preset,submit Run inference,and show source/version/threshold and actual computed score. LR shows intercept/signed logit contributions;K-Means shows cluster/squared distance/deviations. RF local tree SHAP is unsupported.
4. CSV batch:download dashboard/data/phase15_demo.csv,upload it,and click Predict CSV. It contains three synthetic rows:missing,zero and duration/count fixtures. Confirm row numbering,imputation counts and downloadable predictions. Add a nonnumeric field to demonstrate an invalid row remaining in place;remove a required column to demonstrate schema rejection.
5. Historical replay:change capture,replay position and microbatch. Show actual archived volume,detection/novelty summaries and alerts. State explicitly that this is not live packet monitoring. Adaptive versions belong to a separate retrospective experiment.
6. Evidence/reproducibility:show model hashes,source docs,scientific limitations and original figure downloads. Review the new inference contract and deployment restrictions.

Use the genuine screenshots and browser receipts under reports/phase15_validation. New uploaded-record explanations are computed from the selected model;archived explanation tables are labeled research evidence. Never represent a synthetic fixture or retrospective replay as newly observed real traffic.
