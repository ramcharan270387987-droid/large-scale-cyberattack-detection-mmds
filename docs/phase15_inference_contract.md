# Phase 15 inference contract

Supported source-domain pipelines are B-logistic_regression,B-random_forest and B-kmeans. Their exact source versions,component SHA256s,ordered18features,medians,scaler flags/parameters,thresholds and portable hashes are in manifests/phase15_models.json and dashboard/models/phase15_*.json. Exported RF leaves contain probabilities,not private observations. K-Means preserves its original signed-log1p before imputation and standardization. Model parameter distribution is owner-authorized;the source mirror declaresApache2.0,while uncertain upstream provenance remains documented.

Manual fields and CSV use the same exact feature order. Blanks map to stored training medians;finite values must lie in[0,1e12]. This is a bounded admissible input domain,not a model change. Negative,nonnumeric,NaN/infinite and out-of-budget values are rejected. CSV is UTF8/UTF8-BOM,at most1MiB/500logical rows. Duplicate,extra,missing or reordered headers fail with an explicit schema message. Malformed rows remain invalid at their logical row position;valid rows are scored. No uploaded row is silently dropped and no uploaded data fits preprocessing.

LR score is sigmoid(intercept+sum(beta_i*transformed_x_i));the archived fixed0.5threshold determines ATTACK/BENIGN. Signed contributions reconstruct log-odds,not additive probability or causality. RF executes exact archived continuous branch rules and averages original leaf probabilities using stored weights. These are uncalibrated model probabilities,not confidence guarantees. K-Means returns assigned cluster,squared model-space distance and strict distance>archived0.99reference cutoff. NOVEL is not an attack label or probability.

Parity against original Spark4.3.0 pipelines uses deterministic missing,zero,unit,extreme finite,random and tree split-boundary probes. Probability tolerance1e-10;distance relative/absolute1e-8;cluster and threshold decisions exactly equal. See reports/phase15_validation/parity.json. Raw historical rows are not exported. The published synthetic CSV is explicitly a numeric fixture,not a captured or necessarily physically consistent network flow.

Reference-range warnings compare finite inputs to archived Phase4B training min/max from Phase13evidence. They are descriptive,not calibration or validated external-domain coverage. The common3Phase14transfer contract does not authorize archived18feature models on arbitrary external extractors. Hybrid,multiclass/open-set and direct tree SHAP are research-only. Missing/corrupt artifacts disable inference;there is no fabricated fallback.
