# Phase 11 finalization sensitivity plan

This supplemental plan is frozen before executing the remaining Stage 11D comparisons. It preserves phase11-v1 primary configurations, outcomes and calibration. It does not authorize Phase 12.

Reference sensitivity uses lengths 64, 256 and 512. Fixed-reference JS and PSI derive ten quantile bins from independent seed 13013 and 99th-percentile cutoffs from independent stationary seeds 13013–13015, excluding each reference prefix. Adaptive detectors retain their native algorithms and compare reporting warm-up exclusions of 64, 256 and 512 valid observations, bounded below by their native eligibility requirements. Reference/warm-up experiments use stationary, abrupt and recurring streams and evaluation seeds 23013–23015. DDM uses separately declared Bernoulli error streams with error probability .05, .45 after observation 2048 and .05 after 3072 for recurring change. It is evaluated at immediate simulated label availability.

Reset sensitivity compares native continuation, explicit reconstruction after an alert and native updates with 64-arrival alert cooldown. Native continuation is the policy without extra external resets and is evaluated once. All state updates continue during cooldown. Separate raw detections, emitted alerts, external reset counts and suppressed alerts are retained. Two true recurring episodes are matched under the original 512-arrival tolerance.

Missing-input sensitivity uses fixed reference length 256 and abrupt mean shifts. Profiles are stationary 10% random missingness, a missing burst at arrivals 2048–2303, missing probability .4 after 2048 versus zero before, and nonfinite inputs every twentieth arrival. Compare skipping invalid inputs, calibration-reference median imputation, explicit missingness-indicator monitoring, and fixed-reference histograms with minimum 48 valid observations per 64-arrival window. Invalid values are never replaced with zero. Arrival and valid-update clocks are retained separately. Indicator targets are missingness boundaries, not mean-shift boundaries. Skipped burst intervals do not create detector updates. Imputation medians and histogram boundaries use independent calibration observations only.

Historical minimum-support grids are 1, 100, 1000 and 10000 flow observations per replay window. RF-score and cluster histograms use references from batches 0–2 and per-signal calibration from batches 3–9. Error-rate and prevalence streams respect released-label clocks. Existing feature-JS summaries are reused with their recorded reference definition. Phase 10 pattern-support counts use capture-level units and retain their own denominators. Suppressed outputs are unavailable, never negative alerts. No historical drift-event efficacy metrics are defined.

Agreement uses 64-arrival synthetic intervals and one batch per historical interval. Synthetic DDM is separated from feature-signal detectors. Historical comparisons require the same signal, label-delay assumption and mutually available supported batches. Historical KSWIN and event-level DDM retain their unsupported status. Report exact-interval agreement and separately count one-to-one positive-window matches within one interval. All-zero Jaccard and kappa are undefined. Denominators and exclusive positives remain explicit.

Performance associations are retrospective, with lags 0, 1 and 3 observed replay windows. Correlate JS/PSI scores with matched RF precision, recall, F1, FPR, error, positive prediction rate, PR-AUC and prevalence. Report unweighted Pearson, rank correlation, row-weighted Pearson and eligible-pair counts. Outcome labels become available only at outcome batch plus simulated delay. Future-window associations are descriptive analysis, never detector calibration. Report before/after one-window changes around alerts. Temporal dependence, differing class composition and family/day confounding prohibit causal or independent-replication claims. No significance tests or row-independent uncertainty intervals are used.
