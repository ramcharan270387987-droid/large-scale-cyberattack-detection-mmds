# Phase 15 architecture

Entry point:dashboard/advanced_app.py. It is separate from the protected public dashboard/app.py. One navigation shell contains executive overview,nine research areas,actual interactive inference,historical replay,and evidence/reproducibility. Existing baseline/phase-specific evidence is referenced rather than recomputed. manifests/phase15_evidence.json maps203tables and existing figures to original paths and SHA256s. src/interactive/evidence.py verifies and normalizes allowlisted CSV/JSON. Only immutable research tables use shared Streamlit caching;uploads and predictions are session-local ephemeral values.

src/interactive/portable.py executes compact parameter-only LR,RF and K-Means artifacts from dashboard/models. manifests/phase15_models.json binds their original phase/version/component hashes,feature order,thresholds,runtime/explanation support and parity receipts. Missing/corrupt/unsupported artifacts fail closed. No dashboard network request,Kaggle credential,Java or Spark runtime is needed. The bounded offline exporter alone requires Spark4.3.0 and original private artifacts;it never fits a model.

src/interactive/inputs.py unifies manual and CSV parsing,row errors and spreadsheet-safe exports. LR explanations use the actual transformed input of the new prediction. K-Means preserves signed-log1p,training imputation,scaling,assignment and distance decomposition. RF uses original continuous splits,leaf probabilities and tree weights. It has no invented local tree SHAP. Hybrid and family/open-set research remains available but is not exposed as executable inference.

The replay view selects actual capture/batch/window records and their archived classifier,novelty and alert summaries. Phase12adaptive versions are shown as a separately labeled experiment;they are not retroactively attributed to the Phase6replay. Documentation and figure downloads retain original evidence identity. No packet capture,autonomous retraining,production monitoring or public deployment is implemented.
