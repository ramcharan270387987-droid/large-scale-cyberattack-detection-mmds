# Phase12 inference contract

Input predictors are the ordered18 names in configs/ml_experiments.yaml. Finite masking precedes training-only transforms. Metadata cannot enter the estimator. The active pointer identifies one immutable saved pipeline version and one decision threshold. A candidate can only replace the incumbent at a future arrival after measured completion. Threshold-only adaptation changes operating point without fitting coefficients.

Repeated request IDs persist across registry recovery. Model records are immutable, active pointer writes use fsync and atomic rename. A dangling pending file cannot replace the committed pointer. Independent reload must verify hashes, schema and scoring probes before restoring a saved model. Predictions issued by prior versions remain unchanged.

Distribution alerts use an unchanged initial-fit flow-duration reference and do not depend on evolving model scores. They do not prove conditional drift or forecast a performance drop. Unsupported warm-up is explicitly separate from no alert. The isolated preview displays historical aggregate research artifacts and performs no live autonomous retraining.
