# Phase 13 methodology and reproduction

The frozen design is `docs/phase13_research_protocol.md`, committed at98e18753783665fd9b3a0805a623047d3af01ede before historical scoring. The subsequent sampling correction is recorded in `docs/phase13_methodological_amendments.md`. It changes the choice of metadata representative within a predictor group, while retaining the same numerical predictors and frozen model policies.

The four private versions of `ramcharan2345/mmds-phase-13-explainable-ai` partition the work into exact supervised reconstruction, permutation/distributions, components/stability and full-support diagnostics. Builders use the pinned Phase2 producer, original Phase4 population logic and original archived component hashes. Temporary notebooks embed original weights privately and are excluded from Git. Pipeline fitting is absent from the Phase13 execution modules.

`src/explainability/exact.py` implements stable sigmoid, finite/dimension guards, logistic contributions and centroid squared-distance decomposition. Exact additivity is checked against Spark rawPrediction/probability or distance, independently of any importance ranking. The optional tree library attempt is accepted only if it reconstructs the exact archived estimator's outputs. `tests/test_phase13_shap.py` checks the centered linear interventional expression by enumerating all feature coalition orders in a small independent game.

`sample_groups` chooses a deterministic representative using fingerprint, day and labels, and then selects predictor keys by seeded hash. Each key has one primary vote. Reported multiplicity is the number of represented source rows. Multiplicity-weighted averages are sensitivity estimates for the sampled represented groups, not full-population estimators. Two sample seeds, nested100/500/1000 observations, two background seeds and training-only32/64 backgrounds provide48 prespecified linear variants. Capture deletion changes empirical composition without refitting a background or model.

Permutation uses exactly the same1000 observations before and after perturbation. A donor permutation is shared across features in each related-feature group. Within-capture donors retain the capture label. There are18 single features plus count/size and timing groups, three seeds and two scopes, with one baseline:121 conditions per model. Whole-score2048-bin histograms preserve ties. The independent metric tests cover single-class undefined values and exact confusion counts. Summary spreads are descriptive repetition ranges.

Training quantiles define the reference feature ranges and JS bins. For each protocol/feature, approximate training10th/50th/90th cuts are deduplicated; finite values are assigned by strict greater-than, with a separate missing bucket. Both full eligible role populations are counted. JS divergence uses base2 logarithms and lies between0 and1bit. Evaluation labels do not choose bins. Quantiles, missing counts and outside-training-min/max counts are retained separately. These describe marginal shift; correlated/joint shift and causal drift are unresolved.

The rare-case study first counts every eligible test observation by capture, family and fixed0.5 outcome. It then takes at most8 deterministic fingerprint-hash cases per observed stratum, at most1000 per protocol. Original model preprocessing and exact LR decomposition are used. Full eligible support, enriched explained support and primary predictor-group sample support remain separate denominators. No unsupported false-positive or known-family cell is filled with invented values.

Adaptive comparisons reuse the initial and prespecified first activated Phase12 artifacts. Three fixed synthetic inputs support public local explanations. A second matched32-probe set comes only from the initial training captures,14–15 February2018; source IDs and raw values are never published. All compared pipelines score the same probes in fingerprint order. Coefficients divided by original per-model standard deviations provide raw-unit comparisons, alongside imputation/scaler/intercept changes. Actual issued historical metrics and threshold-only P3 events are copied from archived Phase12 evidence, preserving release and activation chronology.

Reproduction uses the existing `scripts/kaggle_web_api.py` wrapper and injected secret without displaying credentials. `scripts/retrieve_phase13.py` requires a terminal completion marker and checks every output receipt hash before copying public allowlisted files. `scripts/analyze_phase13.py` derives tables; `scripts/render_phase13_figures.py` produces provenance-hashed PNG/SVG; `scripts/validate_phase13_preview.py` and `scripts/browser_phase13_preview.py` exercise the isolated laboratory. `scripts/register_phase13_explanations.py` binds methods to exact ordered feature maps and evidence hashes. `scripts/verify_phase13_completion.py` checks the resulting scientific, regression, UI and protected-reference evidence.

All runtimes are bounded single-driver batch measurements. Raw records, model weights and per-row historical explanations remain in private Kaggle archives. The public preview displays archived aggregates and explicitly synthetic examples. Attribution is model-dependence evidence, with the limitations in `docs/phase13_limitations.md`.
