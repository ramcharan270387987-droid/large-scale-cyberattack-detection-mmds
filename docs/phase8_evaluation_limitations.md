# Phase 8 evaluation limitations

B and C are retrospective benchmarks whose outcomes were examined in earlier phases. The rolling folds enforce ordered dates and group separation within the same previously studied corpus. There are ten capture days, with attack families strongly associated with individual captures. Within-day and predictor-group dependence invalidate sample-size arguments that count flows as independent replicates.

The 1% operating budget applies to the operating split. Report realized evaluation FPR with recall and precision. Comparisons with different realized FPRs describe tradeoffs. A policy selected using an evaluation ROC curve would be descriptive and cannot be substituted for the frozen operating point. Hypothetical prevalence PPV assumes transferable sensitivity and specificity. The Web holdout is particularly sensitive to even small false-positive burdens.

Use post-purge support and explicitly report absent families. The earliest-role predictor purge subsumes exact and canonical input collisions where their feature projections agree. The after-imputation check is a distinct diagnostic. Retrospective comparisons preserve the original effective cohorts in the presence of imputation-induced equivalence. The committed paired-count and per-day tables report observed variation. Confidence intervals were omitted because the study has too few independent temporal capture units. The Phase 8 candidate grid uses a single prespecified training seed. New LR and tree models fit on deterministic group samples. Full-population LR and additional retraining seeds were outside the bounded CPU sweep.

The full weight grid has operating-split scores and fit costs. Held-out scoring retains the unweighted and validation-selected candidates per algorithm. Artifact sizes are available for persisted models. Run-level and fit-level JVM high-water marks were recorded. Python RSS was not sampled independently. Single-node Spark timings include query execution and may reflect cache effects.

Calibration metrics use binned midpoint approximations. The registry reports the fitted Platt coefficients. Post-hoc held-out recalibration slope and intercept were not estimated. Novelty percentiles are reference-relative. The learned-fusion decision score has no separate held-out probability calibration. A false alarm analysis based on the dataset cannot establish production efficacy. New independent data and matched operating decisions are necessary before deployment claims.
