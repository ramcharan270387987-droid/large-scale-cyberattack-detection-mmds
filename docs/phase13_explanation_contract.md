# Phase 13 explanation contract

Every explanation refers to a frozen archived pipeline, source notebook version and component SHA256 map in `manifests/phase13_models.json`. Original trained weights remain in private versioned Kaggle archives. The feature vector comes from that pipeline's imputer, assembler and scaler, in the estimator's actual order. All-null dropped inputs cannot silently re-enter the map. The metadata, score domain, method, training reference and sample configuration accompany the public aggregates.

Binary logistic regression uses the exact stored coefficient vector and intercept. Its uncentered decomposition is `intercept + sum(beta_i * transformed_x_i)` in log-odds. Centered contributions are `beta_i * (transformed_x_i - training_mean_i)`, with baseline `intercept + sum(beta_i * training_mean_i)`. Sigmoid converts the reconstructed logit to attack score. Neither decomposition adds in probability space. With an empirical interventional training background this centered form is exact linear SHAP in log-odds; the coalition-enumeration test independently checks the Shapley definition. Correlations make interventional replacement potentially unrealistic and do not create causal evidence.

Native random-forest and GBT importance describes split-based global usage. It is independent of local contribution semantics and may favor correlated or high-cardinality predictors. Permutation importance is baseline minus perturbed performance on identical evaluation rows, with three fixed seeds, global and capture-preserving donors and grouped related predictors. Negative changes are retained. Scores use 2048 whole-score bins; PR area is step-integrated and ROC area trapezoidal. All fixed-threshold metrics use the frozen rule, without explanation-driven threshold selection.

Novelty decomposes squared distance to the actual assigned K-Means centroid in the model feature space. It is not an attack probability. Hybrid reconstruction retains the archived score calibration, novelty reference grid, gates and winning fusion policy. Family explanations retain the class-ID order, maximum-score uncertainty, top-two margin and strict archived rejection-bin rule. Protocol A has no archived rejection cutoff and therefore has no supported rejection-policy claim. Conditional family-stage results never repair earlier binary-gate misses.

The primary explanation sample weights each deterministically selected predictor group once. Flow-weighted sensitivity multiplies each representative by source predictor-group multiplicity; it is a sensitivity measure for the represented sampled groups, not an unbiased full-flow population estimator. Capture composition and rare-case analysis have their own denominators. Stratum-selected cases are descriptive and cannot estimate traffic prevalence. Full-population eligible error support is persisted separately.

Private row-level error explanations and input records remain in private Kaggle outputs. Public local examples use fixed synthetic probes. Reference-derived matched adaptive probes reveal only aggregate contributions and paired score vectors without source IDs or raw inputs. These are retrospective model comparisons and cannot be presented as historical issued predictions. Phase 12 model activation and label-release chronology remain authoritative.

Input schema/dimension mismatches, nonfinite transformed vectors, feature-map mismatches, unknown model identity and failed reconstruction are errors. Missing and extreme synthetic inputs are passed through the actual saved preprocessing in the Spark tests. Undefined metrics remain null. An optional SHAP attempt must pass archived prediction and additivity checks before its values appear in any figure. Unsupported compatibility has a recorded exception and no attributed values.
