# Phase 9 execution methodology

The resumed implementation loads the pinned Phase 2 snapshot, applies the existing primary predictor masking and group hash, and derives numeric attack-family IDs from training support. The main grouped-random population follows Phase 4 A. The chronological population follows Phase 4 B. A family holdout removes every withheld-family predictor group from known training and validation before assigning all withheld-family rows to evaluation.

New classifiers fit the same deterministic 6.25% training predictor sample. Candidate weights use full permitted training support. Inverse weighting uses total training attacks divided by the product of the number of supported classes and family support. Capped weighting clips that weight to ten. Shared median imputation, variance filtering and scaling fit the sampled training partition. LR uses standardized vectors and multinomial loss. RF uses the imputed unscaled vector. Selection uses known validation macro F1, balanced accuracy and fit time.

Before any resumed held-out results were retrieved, the implementation resolved the protocol's unspecified combined rejection operation as the maximum of classifier uncertainty and reference novelty percentile. Maximum-score uncertainty is one minus the largest class score. Margin uncertainty is one minus the difference between the highest two scores. Entropy is normalized by the logarithm of the training class count. The reference K-Means uses twelve centers on the same permitted imputed training sample. Distances use the exact feature representation used to fit its centers. A 257-quantile grid fits reference distances only. This decision is an implementation clarification to phase9-v1.

Known validation selects 1%, 5% and 10% rejection ceilings on 2048 uncertainty bins. Reject bins strictly above the chosen cutoff and accept all cutoff ties. Thresholds are written before scoring known and unknown evaluation data. Accepted correct-family rate divides correctly named accepted known observations by all accepted observations, including unknowns. Chronological closed-set metrics have zero support when every later family is absent from fitting.

The input audit is reused. Each model stage rechecks the attached producer receipt and schema before using the mounted data. Private Kaggle outputs hold selected pipelines, frozen decisions and aggregate evidence. The bounded output retriever compares pipeline file hashes to the saved registry. Checkpoint validation reconstructs test metrics from confusion counts.
