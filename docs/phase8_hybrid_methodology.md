# Phase 8 hybrid methodology

Start with the pinned Phase 2 feature-ready Parquet notebook output version 1. The loader verifies its receipt, schema, label mapping, canonical counts, all capture days and eligibility totals. The private Stage 1 mirror contains the byte-verified Phase 4/5 B and C model files. Imported supervised models and K-Means are checked against the committed hashes, Spark 4.3.0 metadata and ordered imputer inputs. The baseline notebook reconstructs each retained population and reconciles confusion counts and binned AUC values to Phase 4 and strict P99 flags to Phase 5.

The new models use the same defensively masked numerical input contract. A deterministic predictor-group sample fits shared imputation and scaling. LR and RF each test five positive weight rules. GBT tests weights 1 and 5. Selecting an operating point uses an inclusive score bin and never splits a tie. The threshold above one makes no positive predictions. Scores and labels are aggregated to at most 2048 ordered buckets per method before threshold logic or ranking metrics. The AUC implementation uses a trapezoidal ROC integral and step-integrated precision–recall. The published charts thin the curves to a display grid. The AUC computation uses the full histogram.

Platt-style logistic calibration uses weighted bin midpoints, a ridge penalty and clipped logistic arguments. Isotonic uses weighted pool-adjacent-violators and flat endpoint extension. Calibration quality uses midpoint approximations, ten equal-width reliability bins, Brier score, ECE and log loss with epsilon 1e-6. The fitted Platt slope and intercept describe the mapping, whereas ROC and PR-AUC measure ranking. Calibrators use groups that are disjoint from meta-model fitting and operating selection. For rolling probability days, the fixed meta split uses 35% of predictor groups. The retrospective validation uses target proportions of 35% probability, 20% meta and 45% operating.

K-Means distance is squared Euclidean distance in the fitted transform. Its empirical normalization uses a 257-value reference quantile grid and strict-less rank for ties. An extreme score beyond the reference maximum receives a percentile of one. Raw P95, P99 and P99.9 thresholds from the reference sample use strict exceedance. Archived baseline P99 counts remain separate. Learned logistic fusion uses the calibrated base score and the novelty percentile only. Literal OR and AND operate on two validation-derived component decisions and are eligible for selection only if their combined operating FPR meets the primary budget. Weighted endpoints represent single signals. This makes it possible for selection to find no incremental value from combining them.

Test decisions are scored only after a frozen JSON receipt is written with thresholds, model identifiers, calibration parameters, reference grid and fusion specification. Capture day and family may index compact retrospective slices. Neither enters model fitting. The Phase 8 historical inference contract returns risk and evidence fields and supports explicit abstention. ## Reproduce the staged run

Build each notebook with `python scripts/build_phase8_notebook.py --mode MODE --population POPULATION --output STAGE_DIRECTORY/phase8_hybrid_detection.ipynb`. Use `baseline` for B and C before any `hybrid` comparison. Use `hybrid` for B, C, R1 and R2. Submit each build as a private CPU version of the same study notebook. Use the Phase 2 output in all six stages and the verified baseline model mirror for B and C. The experiment manifest records the submitted source references, version, notebook hash and log hash for every stage.

Save each version number, its terminal status and its Kaggle JSON log under its mode-population directory. `scripts/retrieve_phase8_evidence.py` downloads a versioned private result to that stage's `results` directory and checks saved model hashes. `scripts/render_phase8_report.py RUN_DIRECTORY` verifies the receipts and generates the aggregate tables, figures and manifests from those directories. Run the preview in isolation with `python -m streamlit run dashboard/hybrid_preview.py`.
